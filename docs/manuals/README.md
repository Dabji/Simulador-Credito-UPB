# Manuales

Esta carpeta contiene los manuales finales entregables del Simulador de Credito UPB.

| Manual | Archivo | Audiencia |
|---|---|---|
| Manual de usuario | [`Manual_Usuario_Simulador_Credito_UPB.pdf`](./Manual_Usuario_Simulador_Credito_UPB.pdf) | Estudiantes, invitados, administradores y evaluadores funcionales. |
| Manual tecnico | [`Manual de Técnico Simulador.pdf`](./Manual%20de%20T%C3%A9cnico%20Simulador.pdf) | Equipo tecnico, evaluadores, responsables de mantenimiento y CTIC. |

## Relacion con la documentacion del repositorio

- El manual de usuario explica los flujos funcionales finales.
- El manual tecnico consolida arquitectura, base de datos, API, decisiones tecnicas y consideraciones de mantenimiento.
- El manual de despliegue se mantiene en [`../deployment/`](../deployment/) porque pertenece al ciclo operativo de CTIC.
